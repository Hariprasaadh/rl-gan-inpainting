# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

RL-GAN adaptive image inpainting: a frozen Places2-pretrained DeepFill-v2 backbone, four small residual "strategy adapters" (Global / Local / Boundary / Texture), and a Stable-Baselines3 PPO agent that picks one adapter per masked image (1-step contextual bandit). There is no test suite and no linter/formatter config; verification is done by running the CLI/eval scripts. Use the repo `.venv` (Python 3.12, torch 2.6 + cu124) on Windows/PowerShell.

## Architecture

Per image: `(masked_image, mask)` -> backbone **coarse** pass -> `coarse_composite = masked + coarse*mask` -> `StateBuilder` builds a 261-d observation -> PPO picks action 0-3 -> backbone **refine** pass (contextual attention) -> `adapters[action]` -> `completed = masked + refined*mask`. Tensors are in [-1, 1]; masks are 1 = hole; `masked_image` has the hole zeroed.

- **`src/models/rl_inpainting_model.py` (`RLInpaintingModel`)** is the single model every inference path uses. It wraps `deepfillv2.py` (`DeepFillV2Generator`, a subclass of `networks_tf.Generator`; exposes `coarse_forward`, `refine_forward`, `get_bottleneck_feature`), `encoder.py` (`DeepFillEncoder`) and the adapters. `strategy=None` in `refine()`/`forward()` returns the backbone-only result (the "Stage A"/baseline everywhere). `load_pretrained_backbone` also freezes the backbone; `load_adapters` loads the adapters and strategy embeddings.
- **Adapters (`strategy_adapters.py`)** operate on the 3-channel RGB output of the refine stage: conv-IN-ELU with FiLM from a 64-d strategy embedding, conv, then `tanh(x + 0.5*tanh(delta))`. Global is the plain pass; Local scales the input by `1+0.5*mask`; Boundary blends with a dilate-minus-erode ring; Texture adds a Laplacian high-pass term inside the hole plus a small HF branch.
- **State (`src/rl/state.py`)**: 261 = 256 latent + 4 mask stats + 1 boundary-gradient value. The latent is the coarse bottleneck (`conv10_atrous`, 96 channels = 2*cnum) -> global average pool -> 2-layer head. Mask stats (`data/mask_generator.compute_mask_stats`): missing ratio, bbox ratio, `num_regions` = components/10 clipped to [0,1], centroid distance. The boundary value is the mean Sobel magnitude on a 1-px ring outside the hole of the coarse composite, /2, clipped.
- **Actions/rewards**: `src/rl/actions.py` holds ids, names and costs (0 / 0.10 / 0.15 / 0.20; `ACTION_STOP=4` is used by the multi-step environment). `reward.py`: `alpha*dPSNR/10 + beta*dSSIM/0.1 - gamma*dLPIPS/0.1 + delta*dDisc - lambda*cost`, deltas versus the coarse composite, each clipped to ±2, total clipped to ±10. Weights `(alpha,beta,gamma,delta,lambda)` come from `configs/rl_agent_bandit.yaml`: `[1,1,0.5,0.3,0.1]`.
- **`env_bandit.py`** (`InpaintingBanditEnv`): one-step episodes; `step()` computes the reward and draws the next sample; LPIPS is computed when `compute_lpips` is true (the config enables it).
- **Training**: `pretrain_adapters.py` trains each adapter on the same batch with its own loss (one Adam over adapters, embeddings and encoder head; backbone frozen). `train_rl_bandit.py` builds the model (seed 42), loads backbone and adapters, freezes the adapters, creates a `SNPatchGANDiscriminator` for the reward's discriminator term and trains PPO.
- **Evaluation stages** (`scripts/run_multi_image_test.py`): A backbone only; B fixed adapter 0; C PPO-selected feed-forward; D = C + 400 AdamW steps against the ground truth (oracle). The three test scenes use hand-designed masks (`build_controlled_mask`) on sample-image indices 1, 2, 5. `severity_eval.py` buckets by missing ratio (10-20 / 20-40 / 40-60 / 60%+).
- **Web app (`app.py` + `web/`)**: `http.server` with `POST /api/inpaint` (base64 image + mask, `mode` = `fast`|`precision`, optional `action`) and `GET /api/presets`, `/api/image/<name>`. Precision mode runs 60 AdamW steps on the chosen adapter against the uploaded image and then restores the weights. `elapsed_ms` covers the coarse pass, state, policy, baseline pass, adapter pass and PSNR/SSIM computation. Without a PPO zip the server uses action 1.
- **Earlier small-generator line of work**: `src/models/generator.py` (`InpaintingGenerator`), `pretrain_gan.py`, `train_rl_ablations.py`, `joint_finetune.py`, `env_multistep.py` and `src/baselines/lama_inference.py` (a LaMa-style reference network) belong to a separate, earlier experiment set that does not use DeepFill.

## Conventions

- `main.py` is the CLI entry point and adds the repository root to the import path; the scripts in `scripts/` that are run directly (`verify_strategies.py`, `evaluate_baseline.py`) add it themselves.
- `src/utils/seed.py` (`seed_everything`) seeds Python, NumPy and PyTorch; training scripts call it with seed 42.
- Config values are read with `trainer_utils.load_config`; checkpoints are saved with `save_checkpoint`.
